# Проект "online_store"

## Описание:

Проект "online_store" является ядром для интернет-магазина.
В модуле catalog.py реализованы классы для представления товаров и их категорий.
Так же в модуле utils.py реализована функция creates_objects_from_json,
читающая данные из файла JSON и возвращающая список экземпляров класса Category.

## Установка:

1. Клонируйте репозиторий:
```
https://github.com/dmitryshvarev/online_store.git
```

2. Установите зависимости:
```
pip install poetry
```
## Тестирование:

- с помощью библиотеки pytest в проекте протестированы классы Category и Product,
  все тесты выполнены успешно
- с помощью pytest-cov сгенерирован отчет о покрытии кода тестированием, который находится в папке htmlcov в файле с названием 
index.html
